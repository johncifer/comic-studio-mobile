# 漫画镜头工坊 · 手机端网页

**单文件手机网页，浏览器直接打开即用，零安装、零联网、不依赖电脑。**

底部四个标签：**📚漫画 / 🎙导演台 / 🧹去黑条 / ✍FleshOut**。

---

## 怎么用（三步）

1. 把 `web-lite/index.html` 传到手机（微信文件传输 / 数据线 / 网盘均可）。
2. 手机浏览器（Chrome / Edge / 系统浏览器）打开它。
3. 底部切到对应标签使用，结果都「导出」下载到手机。

---

## 四个标签

| 标签 | 功能 | 说明 |
|---|---|---|
| 📚 漫画 | 浏览 / 标注 | 选手机项目文件夹读入全部图片；分镜框、对白、涂鸦、上色、撤销、导出 PNG |
| 🎙 导演台 | 台词核对 | 导入电脑端识别的项目（json/txt）或粘贴台词本 → 逐行可编辑 + 已核对勾选 → 导出 txt/json |
| 🧹 去黑条 | 去条带 | 选图 → 裁剪纯黑边 / 色调条带平滑（保守，零线条损伤）→ 前后对比 → 导出 PNG |
| ✍ FleshOut | 润色 | 本地：导入正文→生成大纲/角色表、格式化对白、导出；API：填你的 LLM 接口做 AI 润色 |

---

## 必须说清的限制（浏览器硬约束，非 bug）

1. **不能写回原文件夹 / 原文件**：纯网页受沙箱限制，标注、去黑条、润色结果都只能「导出下载」，需手动存到手机。
2. **选文件夹兼容性**：安卓 Chrome / Edge 支持「📁 选择项目文件夹」；iPhone Safari 不支持选文件夹，请改用「或选择单张/多张图片」，或用安卓 / 电脑 Chrome。
3. **导演台**：配音生成（TTS）与 OpenCut 导入需电脑端，本网页不接后端，只做台词核对与导出。
4. **FleshOut · API 模式**：浏览器跨域（CORS）可能拦截请求，需你的接口允许跨域或经代理。本地模式无需联网。
5. **去黑条为纯前端启发式**：裁剪纯黑边可靠；条带平滑为轻度保守处理（仅作用于偏暗低方差的均匀条带），非 PC 端的角度检测 + inpainting 重算法，重条带可能去不干净。
