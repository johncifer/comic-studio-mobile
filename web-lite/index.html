功能
📁 文件管理
📚 漫画浏览 / 标注

点左上角 ☰ → 文件管理，浏览手机里的漫画文件夹。点图片即可进入大图标注，写回原文件夹。

🎙 导演台 · 台词核对

参考电脑端：载入项目（json）→ 按页看台词、逐句核对、合并导出。
点左上角 ☰ → 文件管理，选一个 .json 载入；或网页模式用下方「导入文件」。

📄
🧹 去黑条 / 去条带

纯前端处理。点左上角 ☰ → 文件管理选图片，或网页模式用「选择图片」。自动裁黑边 + 条带轻度平滑（零线条损伤），前后对比后导出。

✍ FleshOut · 润色

导入或粘贴小说 / 台词正文，本地生成大纲、角色表，并格式化对白。点左上角 ☰ → 文件管理选 .txt；或网页模式用「导入文件」。

填你的 LLM 接口（OpenAI 兼容 /chat/completions）。浏览器跨域(CORS)可能拦截，需接口允许跨域或用代理。
